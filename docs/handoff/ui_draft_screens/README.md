# 인수인계 근거 탐색 — UI 초안 핸드오프 노트

이 폴더의 스크린샷은 **실제로 실행한 Streamlit 앱을 브라우저(Chrome)로 렌더링해 캡처**한 것입니다(합성 데이터, mock 백엔드).
Figma 재디자인용 참고 화면입니다.

| 파일 | 화면 |
|---|---|
| `1_request.png` | 인수인계 자료 만들기(요청) |
| `2_summary.png` | 인수인계 요약 + 클릭 가능한 `[근거 1]` |
| `3_excerpt.png` | 근거 패널 — 허용된 발췌 |
| `4_restricted.png` | 근거 패널 — 근거 열람 제한(권한 종료 후 동일 링크) |
| `5_original.png` | (참고) 근거 패널 — 원문 근거 위치(권한 있는 리뷰어, 마스킹된 원문) |

## 화면 순서
1. **인수인계 자료 만들기** → 작성자·업무·수신자 입력, 목적/채널은 이 시나리오에서 **고정값**, `자료 만들기`.
2. **인수인계 요약** → 수신자/목적/채널 + 허용된 요약. 인용 문장 옆 `[근거 1]` 버튼. 무효 인용은 링크 없이 "근거를 확인할 수 없습니다".
3. **근거 패널**(하나의 패널, 3상태) → `[근거 N]` 클릭 시 열리고 `요약으로 돌아가기`로 복귀.

## 근거 3상태 (서버 `outcome`이 유일한 근거)
- **원문 근거 위치**(`original`): 출처·페이지·버전 + "마스킹된 근거" 본문. (원본 열람 권한이 있는 뷰어만)
- **허용된 발췌**(`excerpt`): 출처 제목 + 허용된 발췌. **페이지·문서버전은 표시하지 않음.**
- **근거 열람 제한**(`restricted`): 안전한 안내 + 다음 단계. **제목·페이지·미리보기·본문을 모두 비움.**

## Figma에서 자유롭게 바꿔도 되는 것
- 레이아웃·간격, 타이포그래피, 색상·배색, 아이콘, 버튼/헤딩 문구, `[근거 N]`의 시각 형태(칩/각주/밑줄 등), 요약·패널 배치.

## 디자인이 반드시 지켜야 하는 상호작용 규칙
1. **근거 상태는 정확히 3가지**뿐 — 서버 `outcome`만 신뢰, 화면에서 추측/합성 금지.
2. **클릭마다 새 인증 요청** — 캐시된 결과 재사용 금지(응답 `Cache-Control: no-store`). 권한은 매 클릭 서버 재확인.
3. **열람 제한 상태는 아무 정보도 노출하지 않음** — 이전에 보였던 제목/페이지/미리보기/본문까지 지움. 색이 아니라 **상태 문구**로 구분되게.
4. **발췌 상태는 출처 위치(페이지·버전)를 숨김** — 제목과 허용된 발췌만.
5. **링크에 자격 증명·원문 메타데이터 없음** — 서버 발급 불투명 ID만(`{label, evidence_id, url}`).
6. **로딩 / 인증 실패 / 요청 오류**는 "접근 제한"과 **별개**로 표시. 상태 텍스트는 항상 보이게(색 의존 금지).
7. **권한 변경 컨트롤은 일반 열람자 화면에 두지 않음** — 관리자/보호 경로에만(데모 expander는 관리자 전용).

## 실행 방법(실물 확인)
```
# 터미널 1 — mock 백엔드
RAGSEC_LLM_BACKEND=mock RAGSEC_API_KEY=<키> RAGSEC_MAX_DISTANCE=2.0 \
  uv run uvicorn ragsec.api:app --host 127.0.0.1 --port 8000
# (최초 1회) 합성 문서 1건 업로드 후 인수인계 생성 가능
# 터미널 2 — Streamlit
RAGSEC_API_URL=http://127.0.0.1:8000 RAGSEC_API_KEY=<키> \
  uv run streamlit run ui/streamlit_app.py --server.port 8501
```
> 효능 파일럿은 HOLD입니다. 이 화면은 benign 합성 경로만 보여주며 효능 결과가 아닙니다.
