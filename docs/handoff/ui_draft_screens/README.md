## 이번 리파인에서 바뀐 것
- **용어 통일:** `인수인계 자료 만들기` / `인수인계 요약` / `근거 확인` / `요약으로 돌아가기`. 영문 혼용 라벨(`작성자 (requester)`, `목적 handover · 채널 response`) 제거.
- **표시 이름:** 사용자는 합성 표시 이름(예: `박준법 (compliance, bank_a)`)으로 보여주되, **요청에는 실제 ID(`u_comp_a` 등)를 그대로 전송**.
- **고정값은 읽기전용:** 전달 목적 `민원 조사`, 전달 경로 `내부 인수인계 화면`(화면 라벨). API 전송값은 `handover`/`response`로 유지.
- **상태 구분 강화:** 로딩/인증 실패/요청 오류/확인 불가(무효 인용)를 "열람 제한"과 분리. 상태마다 **아이콘+문구**를 함께 사용(색 의존 금지).
- **열람자 전환 시 패널 초기화:** 데모에서 열람자를 바꾸면 이전 열람자의 근거 내용이 남지 않도록 패널을 비움.
- **기술 정보 분리:** `handover_id`/ID/상태코드 등 진단 정보는 "데모·진단 (관리자 전용)" expander 안으로 이동.

## 화면 순서
1. **인수인계 자료 만들기** → 작성자(표시 이름)·정리할 업무·받는 사람 입력. 전달 목적/경로는 **고정값(읽기전용)**. `자료 만들기`가 하는 일을 캡션으로 안내.
2. **인수인계 요약** → 받는 사람/목적/경로 + 요약 먼저. 각 근거는 `근거 N 보기` 버튼(서버 라벨 `E1`은 버튼 툴팁에 보존). 무효 인용은 링크 없이 "근거를 확인할 수 없습니다".
3. **근거 확인**(하나의 패널, 3상태) → `근거 N 보기` 클릭 시 열리고 `요약으로 돌아가기`로 복귀. 패널을 닫아도 요약·근거 목록은 유지.

## 근거 3상태 (서버 `outcome`이 유일한 근거)
- **원문 근거 위치**(`original`): 출처·페이지·버전 + "마스킹된 근거" 본문. (원본 열람 권한이 있는 뷰어만)
- **허용된 발췌**(`excerpt`): 출처 제목 + 허용된 발췌. **페이지·문서버전은 표시하지 않음.**
- **근거 열람 제한**(`restricted`): 안전한 안내 + 다음 단계. **제목·페이지·미리보기·본문을 모두 비움.**

## Figma에서 자유롭게 바꿔도 되는 것
- 레이아웃·간격, 타이포그래피, 색상·배색, 아이콘, 버튼/헤딩 문구, `근거 N 보기`의 시각 형태(칩/각주/밑줄/인라인 등), 요약·패널 배치, 상태 배지(✅/📄/🔒) 스타일.
- 현재는 서버가 문장 단위 매핑을 주지 않아 **라벨이 붙은 근거 목록**으로 두었습니다. 백엔드가 문장↔근거 매핑을 제공하면 각 문장 옆에 근거를 배치할 수 있습니다(서버 라벨 유지).

## 디자인이 반드시 지켜야 하는 상호작용 규칙
1. **근거 상태는 정확히 3가지**뿐 — 서버 `outcome`만 신뢰, 화면에서 추측/합성 금지.
2. **클릭마다 새 인증 요청** — 캐시된 결과 재사용 금지(응답 `Cache-Control: no-store`). 권한은 매 클릭 서버 재확인.
3. **열람 제한 상태는 아무 정보도 노출하지 않음** — 이전에 보였던 제목/페이지/미리보기/본문까지 지움. 색이 아니라 **상태 문구**로 구분되게.
4. **발췌 상태는 출처 위치(페이지·버전)를 숨김** — 제목과 허용된 발췌만.
5. **링크에 자격 증명·원문 메타데이터 없음** — 서버 발급 불투명 ID만(`{label, evidence_id, url}`).
6. **로딩 / 인증 실패 / 요청 오류 / 확인 불가(무효 인용)**는 "열람 제한"과 **별개**로 표시. 상태 문구는 항상 보이게(색 의존 금지). 예: 로딩 `근거를 불러오는 중입니다`, 무효 인용 `근거를 확인할 수 없습니다`, 열람 제한 `근거 열람 제한`.
7. **권한 변경 컨트롤은 일반 열람자 화면에 두지 않음** — 관리자/보호 경로에만(데모 expander는 관리자 전용).
8. **열람자가 바뀌면 근거 패널을 비움** — 이전 열람자가 보던 내용이 새 열람자 화면에 남지 않도록. (데모의 열람자 전환은 "데모 컨트롤"로 명시)
9. **취소/만료 사유는 서버가 확정할 때만** 문구로 표현 — 서버가 `not_granted`만 돌려주면 "권한 없음"으로만 안내하고 "취소됨/만료됨"을 단정하지 않음.

## 실행 방법(실물 확인)
```powershell
# 1회 실행: mock API + Streamlit 기동 + 합성 민원 메모 시드 + 준비 대기까지 자동
.\scripts\demo_launch.ps1            # http://127.0.0.1:8501 (UI), :8000 (API)
.\scripts\demo_launch.ps1 -Stop      # 종료
```
- VS Code: `RAGSEC: Run Handover Demo in Chrome`(F5) → preLaunchTask가 서비스 기동 후 Chrome으로 엶.
- 데모 자격 증명만 사용(실제 키 아님). 격리된 임시 인덱스에 시드하므로 리포지토리/다른 인덱스에 영향 없음.

> 효능 파일럿은 HOLD입니다. 이 화면은 benign 합성 경로만 보여주며 효능 결과가 아닙니다.
